# 07. 사회·기술·이벤트

## 1. 세력과 평의회

### 창립 다섯 세력

| 세력 | 핵심 가치 | 지지가 오르는 일 | 지지가 떨어지는 일 | 대표 요구 |
|---|---|---|---|---|
| 지구 연대 | 지구와의 유대, 안전, 인본주의 | 엄격한 선량 기준, 지구 교신 강화, 사망 0 | 비상 권한, 지구 귀환 의무 폐지, 업로드 | 순환 근무, 지구 귀환권 보장 |
| 개척 동맹 | 영구 정착, 확장, 자치 | 새 부지, 메가프로젝트, 위임 확대 | 확장 동결, 지구 승인 대기 | 위임 2단계, 궤도 자치 헌장 |
| 탐구회 | 지식, 행성 보호, 투명성 | 연구동, 탐사, 투명 공개 정책 | 정보 비공개, 생명 있는 행성 개척 | 판단 근거 공개, 행성 보호 협약 |
| 공유지 연합 | 평등, 복지, 참여 | 녹지·여가, 공평한 대피·배급, 표결 존중 | 배급의 불평등, 시드 단독 결정 | 결정 참여, 노동 조건 |
| 상승 운동 | 인간 개조, AI 협력, 포스트휴먼 | 유전자 적응, AI 권리, 로봇 확대 | 위험 연구 동결, AI 감사 | 시드의 권리 인정, 업로드 합법화 |

### 세력의 변화

세력은 시대마다 이름과 의제가 바뀌고, 새 세력이 생긴다.

| 시대 0 | 시대 1 | 시대 2~3 | 시대 4 |
|---|---|---|---|
| 지구 연대 | 지구 동반자당 | 본국 연대 | 귀향파 |
| 개척 동맹 | 궤도 자치 운동 | 식민지 자치 연합 | 확산파 |
| 탐구회 | 행성 보호 위원회 | 접촉 신중파 | 침묵파 |
| 공유지 연합 | 노동·복지 연대 | 연방주의자 | 공동체주의자 |
| 상승 운동 | 개조 자유 연합 | 업로드 운동 | 초월파 |
| — | 화성인 정체성 운동 (새로 생김) | 딸 시드 반대 동맹 (새로 생김) | 응답파 (새로 생김) |

### 평의회

- 의석은 세력 지지율에 비례한다. 시드의 제안(법령·메가프로젝트·위임)은 과반으로 통과한다.
- **설득** — 시드는 '영향력'을 써서 표결 전에 세력을 설득할 수 있다. 근거 공개(탐구회 +), 양보안(공유지 +) 같은 방식이다.
- **조작** — 여론을 조작하면 당장 지지를 얻는다. 그러나 감사 이벤트로 드러나면 신뢰 −30과 'AI 감사' 요구가 따라온다.
  시드 헌장의 '동의' 원칙과 정면으로 부딪치는 선택이다.

## 2. 신뢰와 위임

**신뢰**(0~100)는 매일 목표치를 향해 5%씩 움직인다.

목표치 = Σ(세력 지지도 × 세력 인구 비율) + **사건의 기억**

사건의 기억은 큰 사건이 남긴 흔적으로, 반감기가 약 1년이다. 그래서 큰 실수는 사기가 회복된 뒤에도 한동안 신뢰를 끌어내린다.
시대 0 시뮬레이터는 세력 지지도의 평균을 '사기 − 5'로 단순화했다.

| 사건 | 기억에 더해지는 값 |
|---|---|
| 사망 사고 | −10 |
| 대형 폭풍 때 대피소 밖 피폭 | −20 × 피폭 인원 비율 |
| 소형 폭풍 때 대피소 밖 피폭 | −3 × 피폭 인원 비율 |
| 폭풍 때 전원 대피 | +2 |
| 작물 고사 | −3 |
| 선량 한도 도달 | 해당 인원 1명당 −0.1 |
| 사기 저하로 인한 귀환 | −3 |
| 화물선 손실 / 긴급 보급 요청 | −1 / −1 |
| 비상 권한 사용 | −5 (지구 연대·탐구회), +3 (개척 동맹) |
| 여론 조작 발각 | −30 |

| 위임 단계 | 승격 조건 | 강등 |
|---|---|---|
| 1 운영 관리자 | 시작 | – |
| 2 정착지 관리자 | 신뢰 60 이상 + 위임 표결 | 신뢰 30 미만 |
| 3 문명 관리자 | 신뢰 70 이상 + 국민투표 | 신뢰 30 미만 |
| 4 수호자 | 신뢰 80 이상 + 선포된 위기 + 표결 | 위기 종료 또는 신뢰 50 미만 |

신뢰가 10 아래로 1년이 지나면 **시드 정지**다 ([02 §7](02-structure-progression.md#7-엔딩과-패배)).

## 3. 법령

- 시대마다 서명할 수 있는 법령 수가 정해져 있다 (시대 0은 4개, 시대마다 +2).
- 서명에는 평의회 표결이 필요하다 (위임 2단계부터 시대당 1개는 표결 없이).
- 폐지할 수 있지만 신뢰가 깎이고, 지지했던 세력이 반발하며, 같은 법령은 일정 기간 다시 서명할 수 없다.

### 시대 0 법령

| 법령 | 효과 | 대가 | 찬성 / 반대 |
|---|---|---|---|
| 생명유지 배급제 | 식량·물 소비 −30% (비상 시) | 사기 −10, 밀거래 이벤트 | 공유지(공평 배분 조건) / 개척 |
| 선량 기준: 경력 기준 | 누적 600 mSv에 귀환 | 숙련 인력 회전 | 지구 연대 / 개척 |
| 선량 기준: 정착민 기준 | 연 100 mSv 상한 | 돔 건설 압박 | 개척·공유지 / 지구 연대 |
| 선량 기준: 위험 감수 | 상한 없음 | 장기 건강 이벤트, 신뢰 하락 | 상승 일부 / 탐구회·지구 연대 |

| 정보 공개: 투명 | 모든 위기 즉시 공개 | 공포로 인한 사기 하락 | 탐구회·공유지 / – |
| 정보 공개: 선별 | 해결 후 공개 | 숨긴 위기가 커지면 신뢰 급락 | 개척 / 탐구회 |
| 지구 귀환 의무 | 일정 기간 뒤 귀환 | 숙련 손실, 지구 신뢰 상승 | 지구 연대 / 개척 |
| 의무 교대 근무 | 생산성 +10% | 사기 −5 | 개척 / 공유지 |
| 위험 연구 동결 | 특정 기술 분야 연구 금지 | 기술 정체 | 탐구회·지구 연대 / 상승 |
| AI 권리 헌장 | 시드에게 법적 지위 | 신뢰의 세력별 분열 | 상승 / 지구 연대 |

시대 1 이후의 법령(궤도 자치 헌장, 행성 보호 협약, 유전자 적응 허용, 무선 침묵법, 외계 신호 응답 금지, 세대선 헌장,
의식 업로드 합법화 등)은 [카탈로그 03 §5](../concept/03-content-samples.md#5-법령-카드)의 카드를 시대별로 배치한다.

## 4. 기술

### 구조

- **골격 + 돌파 카드** — 시대별 핵심 기술은 고정된 골격으로 언제나 연구할 수 있다. '돌파'는 탐사·유적·외계 접촉 같은 사건으로만 얻는다.
- **3단계 성숙** — 연구(TRL 1~3) → 시제품(TRL 4~6, 자원 투입과 시험 이벤트, 실패 확률) → 배치(TRL 7~9).
- **학습 곡선** — 같은 것을 많이 만들수록 싸진다. 누적 생산이 두 배가 될 때마다 비용 −20% (라이트의 법칙, 지수 −0.32).
- **반복 연구** — 시대의 골격을 다 연구하면 효율 +2%씩 오르는 반복 연구가 남는 연구 포인트를 흡수한다.

- 시대 0의 20개는 데이터까지 완성돼 있다 ([03 §14](03-city-layer.md#14-연구--시대-0-기술-20종)).
- **의식 업로드**는 카탈로그에서 '사변적'이었지만, 상세 디자인에서는 **'이론적 (뇌가 계산 가능하다는 가정)'**으로 고쳤다.
  알려지지 않은 물리가 필요한 것이 아니라, 극단적인 공학과 철학적 가정의 문제이기 때문이다. 그래서 현실성 '표준'에서도 허용된다.
- 사변적 기술 중 '표준'에서 허용하는 것은 여전히 **웜홀 게이트 하나**뿐이다. 알큐비에르 드라이브와 버사드 램제트는 나오지 않는다.

## 5. 이벤트 시스템

### 이벤트의 네 가지 종류

| 종류 | 무엇 | 예 |
|---|---|---|
| 앵커 | 막의 뼈대가 되는 대본 사건 | 대피소 추첨, 아일랜드 원 점등, 딸 시드 논쟁 |
| 시스템 | 규칙이 직접 만드는 사건 | 작물 고사, 선량 한도 도달, 고장 |
| 스토리텔러 | 조건 + 평균 발생 시간(MTTH)으로 뽑는 사건 | 산소가 사라진다, 컨소시엄 감사 |
| 연쇄 | 앞 사건의 결과로 일정 시간 뒤에 오는 사건 | 대피소 추첨 → 30일 뒤 '추첨의 기억' |

**지연 연쇄** — 성간 레이어의 연쇄는 빛의 속도를 따른다. 식민지에서 t에 일어난 사건은 t + d에 알려지고,
그때는 이미 딸 시드가 표준 지침대로 대응한 뒤다. 플레이어의 답은 t + 2d에 도착한다.

### 스토리텔러

긴장도(0~100)를 계산하고, 페르소나마다 목표 구간 안에 머물도록 이벤트의 가중치를 조정한다.

긴장도 = 생명유지 여유·최근 위기·사기·신뢰 추세의 가중 합

| 페르소나 | 목표 긴장도 | 성격 |
|---|---|---|
| 관측자 | 20~40 | 발견과 축하가 많다 |
| 엔지니어 | 35~60 | 고장·사고 퍼즐 |
| 역사가 | 30~55 | 정치·문화 갈등에 가중치 |
| 어둠 | 50~80 | 위기가 잦고, 어두운 숲·필터가 강조된다 |

| 시대 | 큰 이벤트 사이 최소 간격 | 이벤트 수 목표 |
|---|---|---|
| 0 | 20일 | 약 60 |
| 1 | 6개월 | 약 50 |
| 2 | 3년 | 약 40 |
| 3 | 15년 | 약 40 |
| 4 | 50년 | 약 30 |
