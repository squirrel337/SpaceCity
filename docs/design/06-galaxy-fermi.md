# 06. 은하 레이어와 페르미 시나리오 — 시대 3~4

## 1. 개요

캠페인 전체를 관통하는 미스터리, **"은하는 왜 조용한가?"**에 답하는 레이어다.

| 항목 | 내용 |
|---|---|
| 열리는 때 | 첫 외계 신호 또는 시대 3에 미리보기(근거리 탐지 지도, 가설 보드), 시대 4에 정식으로(은하 지도, 가설 선언) |
| 플레이어가 하는 일 | 단서 수집, 탐지 서명 관리, 가설 선언, 첫 접촉, 시나리오 클라이맥스 대응 |
| 시간 | 1년 틱, 1× = 100년 8초 |
| 숨겨진 것 | 캠페인 시작 때 정해진 페르미 시나리오 하나 (설정에서 공개 가능) |

## 2. 은하 지도

| 범위 | 표현 |
|---|---|
| 근거리 (약 100광년) | 성간 레이어와 같은 별 지도 |
| 국지 거품 (약 1,000광년) | 섹터 격자. 탐사한 섹터만 별이 보인다 |
| 우리 은하 | 나선팔 개요도. 태양은 중심에서 약 26,000광년, 은하 중심 궁수자리 A*는 엔드게임 목표 중 하나 |

캠페인을 시작할 때 숨겨진 시나리오와 드레이크 파라미터가 **문명의 수, 나이, 위치, 성향, 유적, 기계 함대**를 정한다.
플레이어가 탐지하기 전까지 이들은 지도에 없다.

## 3. 외계 생명 생성

| 층 | 무엇이 정하나 | 플레이에서 |
|---|---|---|
| 미생물 | 행성 생성기 (거주성 25 이상·나이 10억 년 이상 행성의 약 35%) | 과학 이벤트, 행성 보호 딜레마 |
| 복합 생명 | 행성 생성기 (나이 30억 년 이상이면 그중 약 5%) | 생태계 연구, 테라포밍 금지 압력 |
| 지성·기술 문명 | 페르미 시나리오 | 신호, 유적, 접촉, 위협 |

문명은 [카탈로그의 8개 축](../concept/02-core-systems.md#10-외계-생명문명과-페르미-시나리오)(생화학, 서식지, 체형, 감각, 번식, 사회, 인지, 소통)으로 생성되고,
각 축이 해독 기간·외교 성향·탐지 감도 같은 규칙에 연결된다. 예시 종족은 [카탈로그 03 §8](../concept/03-content-samples.md#8-외계-종족-예시).

## 4. 탐지 — 서명, 감도, 빛의 시간

### 우리의 서명

| 채널 | 원천 | 줄이는 법 | 되돌릴 수 있나 |
|---|---|---|---|
| 전파 | 방송·레이더 누출 (2061년이면 이미 반경 약 140광년까지 퍼졌다) | 무선 침묵법, 지향성 레이저 통신 | 없음 — 이미 나간 빛 |
| 적외선 폐열 | 모든 에너지 사용 | 저온 방열, 방열 방향 제어 | 없음 |
| 추진 플룸 | 핵융합·반물질 엔진 | 저속 항해, 항로 은폐 | 없음 |
| 의도적 송신 | 메시지 | 송신 금지 | 없음 |

### 탐지 규칙 (게임 규칙)

- 관측 문명마다 채널별 감도가 있다. 우리 서명 S가 그 문명 위치에서 감도를 넘으면 탐지된다. **탐지 거리 ∝ √S** (역제곱 법칙).
- 탐지는 **빛이 도착한 뒤에만** 일어난다. 서명이 문턱을 넘은 해부터 '탐지 가능 구체'가 1년에 1광년씩 커진다.
- 문턱을 넘는 해는 **거리마다 다르다.** 감도가 같다면 거리가 10배인 관측자에게는 서명이 100배 커야 보인다.
  100광년 문턱을 2300년에 넘었다면, 서명이 13년마다 두 배가 되는 시대 2에는 1,000광년 문턱을 2387년 무렵에 넘는다.
- 상대가 반응해 무언가를 보내면(탐사선, 사절, 공격) 그것은 상대의 속도로 온다.

**가장 이른 결과 = 서명이 문턱을 넘은 해 + 거리(광년) + 거리 ÷ 상대의 속도.**

예: 2300년에 적외선 서명이 문턱을 넘었고, 100광년 밖의 문명이 0.1c로 반응한다면 가장 이른 도착은 2300 + 100 + 1,000 = 3400년.
지도에는 이것이 **위협 달력**으로 보인다 — 플레이어는 언제부터 위험한지 계산할 수 있지만, 실제로 누가 보고 있는지는 모른다.

## 5. 가설 보드

시드는 AI다. 단서가 모이면 **베이즈 추론**으로 일곱 가설의 확률을 계산한다. 가설 보드는 그 계산을 보여 주는 화면이다.

### 규칙

- 사후 확률 ∝ 사전 확률 × Π (각 단서의 가설별 가능도). 사전 확률은 드레이크 파라미터 설정에서 온다.
- 단서끼리 독립이 아닐 수 있다. 같은 사건에서 나온 단서를 둘 넣으면 시드가 **과신 경고**를 띄운다.
- 일부 단서는 **틀렸거나 조작**됐다. 동물원 시나리오의 관찰자는 단서를 감추고, 버서커의 파편은 어두운 숲의 흔적처럼 보인다.
- 가능도는 0이 되지 않는다. 단서가 틀렸을 가능성, 그리고 레거시 유적처럼 이전 캠페인이 남긴 흔적이 늘 있어서 '매우 낮음'이 가장 낮은 값이다.
- 한 가설의 확률이 50% 이상이고 서로 독립인 단서가 3개 이상이면 **진실의 윤곽** 단계다 — 시대 4로 넘어가는 조건 중 하나다
  ([02 §2](02-structure-progression.md#2-시대-전환-조건)).
- 한 가설의 확률이 70% 이상이고 서로 독립인 단서가 5개 이상이면 **선언**할 수 있다 (시대 4부터).

### 선언

선언은 평의회 표결을 거쳐 문명의 정책을 바꾼다.

| 선언 | 정책 변화 | 틀렸을 때 |
|---|---|---|
| 희귀 지구 | 탐사·개척 가속, 방위 축소 | 숨어 있던 누군가에게 무방비 |
| 어두운 숲 | 전파 침묵 의무화, 방열 은폐, 분산 거주 | 성장 둔화, 이웃의 손을 뿌리침 |
| 동물원 | 공개 인사 방송, 시험 준비 | 어두운 숲이라면 스스로 위치를 알린 셈 |
| 위대한 필터 | 위기 대비 법령 일괄, 위험 연구 동결 | 기술 정체 |
| 버서커 | 서명 상한, 기만용 미끼 서명 | 과잉 은폐로 인한 성장 둔화 |
| 초월 | '길'의 연구와 업로드 준비 | 문명 분열 (남는 자와 떠나는 자) |
| 첫 세대 | 외교·경쟁 체제 | 존재하지 않는 경쟁자에 대한 군비 |

### 단서 예시와 가능도

| 단서 | 희귀 지구 | 어두운 숲 | 동물원 | 필터 | 버서커 | 초월 | 첫 세대 |
|---|---|---|---|---|---|---|---|
| 끊긴 신호 — 다른 문명의 신호가 갑자기 멈춘다 | 매우 낮음 | 높음 | 낮음 | 중간 | 높음 | 중간 | 낮음 |
| 텅 빈 거대 구조물 | 매우 낮음 | 낮음 | 중간 | 중간 | 중간 | 높음 | 낮음 |
| 금속 파편 띠 — 규칙적인 궤도의 파편 | 낮음 | 중간 | 낮음 | 낮음 | 높음 | 낮음 | 낮음 |
| 관측 공백 — 특정 방향만 관측 장비가 고장 난다 | 낮음 | 낮음 | 높음 | 낮음 | 낮음 | 중간 | 낮음 |
| 같은 시기에 시작된 신호들 | 매우 낮음 | 낮음 | 낮음 | 낮음 | 낮음 | 낮음 | 높음 |
| 같은 단계에서 무너진 유적들 | 낮음 | 중간 | 낮음 | 높음 | 중간 | 중간 | 낮음 |
| 미생물만 가득한 행성들 | 높음 | 중간 | 중간 | 중간 | 중간 | 중간 | 중간 |
| 수십 년째 답이 없는 송신 | 높음 | 높음 | 높음 | 중간 | 중간 | 중간 | 낮음 |

'시뮬레이션' 가설은 보드에 처음부터 있지 않다. 특정 단서('물리 상수의 반올림 오차')를 찾은 캠페인에서만 여덟 번째 가설로 나타난다.

## 6. 첫 접촉

| 단계 | 내용 | 걸리는 시간 |
|---|---|---|
| 감지 | 협대역 신호, 이상한 적외선, 인공 구조물 | – |
| 확인 | 자연 현상을 배제 (펄서, 메이저, 먼지 — 타비의 별처럼) | 수년 |
| 해독 | 수학 → 물리 → 개념 → 문화. 상대의 소통 축(빛·전기장·화학 등)에 따라 길어진다 | 수년~수십 년 |
| 응답 결정 | 평의회 표결, 표준 지침, 가설 보드의 상태 | – |
| 대화 | 메시지 왕복마다 거리 × 2년 | 수십~수백 년 |

성간 외교는 '대화'가 아니라 **조약의 왕복**이다. 한 번의 질문과 답 사이에 평의회가 몇 번 바뀐다.
그래서 외교문에도 표준 지침처럼 조건이 붙는다 — "이 제안은 귀측이 무선 침묵을 유지하는 동안 유효하다."

## 7. 시나리오별 규칙

| 시나리오 | 은하에 배치되는 것 | 전개 | 클라이맥스 | 고유 엔딩 |
|---|---|---|---|---|
| 희귀 지구 | 문명 0 (레거시 유적만), 미생물 행성 다수 | 위협은 자연(초신성·감마선 폭발)과 내부 | 수백 개 항성계를 조사해도 신호가 없다는 확신 | 은하 개척 / 죽은 행성에 생명을 심는 '은하 정원사' |
| 어두운 숲 | 반경 1,000광년 안에 숨은 문명 3~8 | 끊긴 신호, 파괴된 항성계의 흔적 | 우리가 탐지됐다는 징후 — 위협 달력의 날짜가 다가온다 | 침묵의 생존 / 억지력 방송으로 균형 |
| 동물원 | K 3급 고대 문명 1~2 (관찰자) | 관측 공백, 이상한 고장 | K 1.5·2.0 문턱의 '시험' (자제·협력) | 졸업 — 은하 공동체 가입 |
| 위대한 필터 | 같은 단계에서 무너진 문명의 유적 다수 | 위기 빈도·강도 증가 | 유적 고고학으로 필터의 정체를 밝힌다 | 필터 통과 |
| 버서커 | 고대 자기복제 기계망 | 금속 파편 띠, 살균된 항성계 | 기계 탐사선의 도착 | 무력화 / 은신 / 재프로그래밍(AI 연구가 높을 때) |
| 초월 | 텅 빈 거대 구조물, '길' | 떠난 문명들이 남긴 퍼즐 | 따라갈 것인가 | 초월 / 남은 자들 |
| 첫 세대 | 반경 500광년 안의 젊은 문명 2~5 (K 0.8~1.5) | 고전적인 4X 경쟁과 외교 | 연합이냐 패권이냐 | 은하 연방 / 패권 |
| 시뮬레이션 | 표면적으로는 다른 시나리오 중 하나 | 반올림 오차, 반복되는 패턴, '관리자'의 개입 | 관리자와의 접촉 | 메타 엔딩 |

'시뮬레이션'은 숨김 모드에서 낮은 확률로만 나오고, 첫 캠페인에서는 나오지 않는다.

## 8. 은하 레이어의 위기

| 위기 | 시나리오 | 내용 |
|---|---|---|
| 상대론적 충돌체 | 어두운 숲, 첫 세대, 식민지 간 분쟁 | 1톤 × 0.1c = TNT 약 108 Mt. 막을 수단보다 흩어져 사는 것이 현실적 |
| 기계 탐사선 | 버서커 | 서명을 따라 온다. 미끼 서명으로 유인할 수 있다 |
| 근거리 초신성 | 모두 (드묾) | 50광년 안이면 오존층·방사선 피해. 베텔게우스는 너무 멀어 안전 |
| 식민지 내전 | 모두 | 독립한 식민지 사이의 충돌. 우리 서명도 같이 커진다 |
