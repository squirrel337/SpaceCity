# 03a. 모듈 전체 목록 — 34계열 170종

[03 도시 레이어 §8](03-city-layer.md#8-모듈--34계열-170종)의 기본 모듈 34종은 저마다 한 **계열**의 맏이다.
처음 29계열은 같은 일을 하는 다른 설계 4종씩을 더해 145종이다. 도시 발전 모드와 함께 상업·금융(우주 은행·교역소·우주 호텔),
교통(환승 센터), 첨단 산업(첨단 제조동) 5계열 15종과, 기존 계열의 큰 설계 10종(공동 주택 블록, 계단식 주거동, 종합 연구원,
전파 망원경 배열, 대용량 축전소, 태양광 패널 밭, 레골리스 채석장, 광석 정련소, 조립 공장, 식물원 돔)이 더해져 모두 170종이다
(모양까지 치면 종류마다 다섯 가지, 850가지).
같은 계열은 같은 규칙에 들어가고 수치만 다르다 — 크고 싸지만 자주 고장 나는 것, 작고 튼튼한 것, 전기를 덜 먹는 것,
늦게 연구해야 하지만 효율이 좋은 것. 어느 것도 다른 것을 완전히 이기지 않도록 비용·전력·고장 간격·크기를 맞췄다.

모든 종류는 실제 개념에 근거한다 — 나사 KRUSTY(킬로파워), ISS 생명유지 장치(OGA·CDRA·UPA·WPA), 오리온 아민 흡착기,
ESA MELiSSA(스피룰리나), 나사 RASSOR, 메탈리시스 FFC 공정, ICON·포스터+파트너스의 인쇄 거주지, 나사 '아이스 홈' 같은 것이다.
근거와 장단점은 표의 '기능'과 데이터의 `note`에 있다.

## 계열 규칙

| 규칙 | 내용 |
|---|---|
| 합산 | 계열의 능력은 가동 중인 모든 종류의 합이다 (전해조의 산소, 제거기의 CO₂, 프린터의 인쇄량 …). 가동률·전력도 종류마다 셈한다 |
| 조리법 | 같은 계열은 같은 입출력 열쇠를 쓴다 (보시 반응기는 메탄 0 — 탄소를 고체로 남긴다) |
| 축전 효율 | 배터리 계열은 90%, 재생 연료전지 계열은 50% — 계열이 같은 저장소를 나눠 쓴다 |
| 일조 칸 | 태양광 타워 계열은 모두 능선의 일조 칸을 하나씩 쓴다. 출력 = 종류의 kW × 칸 계수 |
| 인쇄 | 데이터에 `printed`가 있는 종류(돔 계열, 인쇄 거주동)는 레골리스 프린터가 벽을 쌓아야 끝난다 |
| 선량 | 돔 계열은 돔 선량, `dose: covered`인 종류(인쇄 거주동)는 피복 모듈 선량을 받는다 |
| 사기 | 공원·체육관·주방·종자 금고 …의 사기는 합쳐서 최대 +15. 지구 교신은 가동 중인 교신 계열 중 가장 좋은 것 하나만 |
| 연구 | 연구동 계열은 인원(연구원)으로, 그 밖의 `rp_day`(천문대·교신·원격 조종실)는 그대로 더한다 |
| 거리 | 원자로 계열은 사람이 머무는 건물에서 60 m(매립형 20 m, 동위원소 10 m), 착륙장 계열은 다른 건물에서 30 m(방벽·호퍼 15 m) |
| 상업 | `support_day`(은행·교역소·호텔 계열)는 날마다 지구 지원 점수를, `make`(교역소·첨단 제조동 …)는 부품을 가동 중인 수만큼 더한다. 4순위 시설은 절전으로 꺼진 시간만큼 덜 낸다 |
| 건설 가속 | `build_boost`(환승 센터·로버 차고지·자기부상 터미널·로봇공학 연구소)는 로봇의 하루 작업량을 늘린다 — 합쳐서 최대 +50% |
| 자동 운영 | 시드의 추천 운영은 기본 모듈로 짓는다. 시험용 `variety` 정책은 계열의 종류를 돌아가며 짓는다 |

파이썬 밸런스 시뮬레이터와 게임(GDScript)은 이 규칙을 똑같이 셈한다 — `variety` 정책으로 3년을 하루 단위로 비교해 같은 결과가 나온다.
기본 모듈만 쓰는 판(추천·준비 없는 운영)의 결과는 계열을 넣기 전과 한 자리도 다르지 않다.
