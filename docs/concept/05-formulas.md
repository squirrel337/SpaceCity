# 05. 공식 모음

게임에 쓰는 물리·밸런스 공식과 예시 값이다. 모든 값은 [examples/formulas.py](examples/formulas.py)를 실행해 얻었다.

```bash
python3 docs/concept/examples/formulas.py
```

표기: M = 질량(태양 = 1), L = 광도(태양 = 1), a = 궤도 장반경(AU), g = 중력(지구 = 1).

## 1. 항성

| 공식 | 식 | 비고 |
|---|---|---|
| 질량-광도 관계 | M < 0.43: L = 0.23 M^2.3 · M < 2: L = M⁴ · M < 55: L = 1.4 M^3.5 | 주계열성 근사 |
| 반지름 | M < 1: R = M^0.9 · M ≥ 1: R = M^0.8 | 근사 |
| 유효온도 | T = 5,772 K × (L / R²)^¼ | 슈테판-볼츠만 법칙 |
| 주계열 수명 | t ≈ 10 × M / L (10억 년) | |
| 거주가능영역 | d = √(L / S_eff), S_eff는 항성 온도의 4차 다항식 | Kopparapu 외(2014). 보수적: 폭주 온실~최대 온실, 낙관적: 최근의 금성~초기 화성 |
| 설선 | 2.7 √L AU | 바깥쪽에서 거대행성·얼음 천체가 잘 생긴다 |

| 질량 | L | R | T | 주계열 수명 | 예 |
|---|---|---|---|---|---|
| 0.12 | 0.0018 | 0.148 | 3,067 K | 6,844억 년 | 프록시마급 적색왜성 |
| 0.82 | 0.45 | 0.836 | 5,175 K | 181억 년 | 엡실론 에리다니급 K형 |
| 1.0 | 1 | 1.000 | 5,772 K | 100억 년 | 태양 |
| 2.06 | 17.6 | 1.783 | 8,850 K | 12억 년 | 시리우스 A급 A형 |

질량-광도 관계는 오차가 크다. 시리우스 A의 실측 광도는 25.4인데 식은 17.6을, 글리제 876(질량 0.37)은 실측 0.012인데 식은 0.023을 준다.
**실측값이 있으면 실측값을 쓰고**, 절차적 항성에만 이 식을 쓴다. 적색왜성의 실제 수명은 이 식보다 훨씬 길어 수조 년에 이른다.

| 항성 | 보수적 HZ (AU) | 낙관적 HZ (AU) | 설선 (AU) |
|---|---|---|---|
| 태양 | 0.951–1.677 | 0.751–1.769 | 2.70 |
| 프록시마 (L 0.0016, 3,040 K) | 0.042–0.083 | 0.033–0.087 | 0.11 |
| 엡실론 에리다니 (L 0.34, 5,080 K) | 0.576–1.040 | 0.455–1.097 | 1.57 |
| 트라피스트-1 (L 0.00055, 2,570 K) | 0.025–0.050 | 0.019–0.053 | 0.06 |
| 시리우스 A (L 25.4, 9,940 K) | 4.426–7.636 | 3.495–8.054 | 13.61 |

프록시마의 보수적 HZ(0.042–0.083 AU)는 프록시마 b 발견 논문(2016)이 제시한 범위와 거의 같다.
붉은 별일수록 같은 광도에서 HZ가 바깥으로 밀린다 — 단순식 √(L/1.1)~√(L/0.53)을 쓰면 트라피스트-1 g가 HZ 밖으로 잘못 나온다.

## 2. 행성

| 공식 | 식 | 비고 |
|---|---|---|
| 케플러 제3법칙 | P² = a³ / M (P: 년) | 공전주기 ↔ 궤도 |
| 평형 온도 | T = 278.6 K × (L (1 − A))^¼ / √a | A = 반사율. 온실효과 제외 |
| 표면 중력 | g = M / R² (지구 단위) | |
| 탈출속도 | v = 11.19 km/s × √(M / R) | 발사 비용의 근거 |
| 조석 고정 (게임 근사) | a < 0.3 × M_항성^(1/3) AU | |
| 지구 유사도 지수 ESI | ∏ (1 − \|(x − x₀) / (x + x₀)\|)^(w / 4) | Schulze-Makuch 외(2011). 반지름 0.57, 밀도 1.07, 탈출속도 0.70, 온도 5.58 |
